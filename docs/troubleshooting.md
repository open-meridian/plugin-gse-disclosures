# Troubleshooting

## Connection says No files location

Open **Settings** and enter **Files location**: the HTTPS address of the
folder holding the agencies' files.

## Connection says Not answering

The location refused or did not answer. The error beside it names the
address asked and why: an HTTP status other than "not found", or a network
error. Check the address and, if the location asks for one, the token. A
file the location does not hold is never an error: it is taken as not
published yet.

## A pool is declined source silent

None of the last thirteen months' files names the pool: check the location
holds the agency's monthly files under their own names, and that the record's
agency and pool number are right.

## A pool is declined not covered

The record asked for is not a Fannie Mae or Freddie Mac pool or class, or it
was asked of the other agency's dataset, or its pool number meets two
records in the deployment (the Instruments page lists the conflict to merge).
