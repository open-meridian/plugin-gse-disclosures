# Pages

- **Connection** (Manage): whether the files location answers, how many
  requests the plugin made and when it last checked, and the last error.
  Its tool is `read_connection`.
- **Datasets** (Manage): each GSE's dataset, whether it is licensed, what was
  recorded and declined, and the pools and classes kept current. Its tool
  is `read_datasets`.

Neither page shows a factor: the plugins that read factors show them.
